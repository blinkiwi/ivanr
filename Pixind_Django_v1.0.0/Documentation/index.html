Pixind - Django Multipurpose Landing Template

Introduction

Pixind is a fully responsive, clean, and modern high-converting Django landing page template. It is a beautifully handcrafted, pixel-perfect HTML5 landing page template based on the Django v6.x & latest Tailwind CSS V4.x. Pixind comes with 5 one-page home demos, 1 niche demo, and 9 inner pages. All files are organized, and we believe it will be easy to use and edit them. This template is well-organized and very easy to customize. Quick and easy to set up.

Pixind has 30+ pages with fully responsive design in Desktop, Tablet and Mobile devices.

Dark & RTL version Available: We have provided a RTL version in both Dark and Light versions.

Setup Django

Introduction

This approach allows you to run a Django project on a client system without setting up the entire project structure. It assumes you have access to the project's requirements.txt file, which lists all required Python packages.

Prerequisites

Please follow below steps to install and setup all prerequisites:

  • Python

    Make sure to have the Python installed & running in your computer. If you already have installed Python on your computer, you can skip this step .

  • Pip

    Run pip --version in your terminal. If pip is not installed, it usually comes bundled with Python. Download Python again if necessary.

  • Git

    Make sure to have the Git installed globally & running on your computer. If you already have installed git on your computer, you can skip this step.

Installation

To setup the template, follow below-mentioned steps:

  • Install Prerequisites

    Make sure to have all above prerequisites installed & running on your computer

After you finished with the above steps, you can run the following commands into the terminal / command prompt from the root directory of the project to run the project locally or build for production use:

  • Navigate to the project directory:

    Use the cd command to navigate to the directory containing the unzipped project files (assuming it has a requirements.txt file).

  • Install required packages (within the virtual environment):

    Bash
    pip install -r requirements.txt
    This installs the necessary packages for your project inside the virtual environment.

Freezing Dependencies (Optional):
  • Freezing Dependencies (Optional):

    You can create a snapshot of the currently installed packages and their versions using:

    Bash
    pip freeze
    This will update your requirements.txt file with the exact versions of the installed packages. This can be useful for ensuring reproducibility or sharing your project's dependencies in the future.

Frontend Setup:

Frontend (npm) commands are required only for local development when modifying Tailwind or frontend assets.
These commands are not required on production or cPanel servers.

  • Command Description
    npm i This would install all the required dependencies in the node_modules folder.
    npm run dev For compiling Tailwind CSS and frontend assets.
Running the Server
  • Create a new file named:

    .env

    Add SECRET_KEY inside .env run this command:

    Bash
    python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"

  • Run development server:

    Execute the following command:

    Bash
    python manage.py runserver

  • This starts the Django development server, usually accessible at http://127.0.0.1:8000/ by default.
